  • OOP: the worst thing that happened to programming [2/24/2025]
    • Class methods have limited reuse and there are too many ways to override a method with keywords like virtual, overwrride, sealed, new.
    • Inheritance only lets you inherit from a single class and many programmers prefer delegation.
    • Polymorphism hides complexity and bloats codebases.
    • OOP has complicated syntax, a steeper learning curve, and so much feature-overlap that multiple considerations must be made before you even write a line of code.
    • In OOP, data and logic are grouped together making code more complicated and bug-prone.
    • OOP has mutable states making concurrency and multithreading more complicated.
    • Use langauges like Go or C that lacks classes.
